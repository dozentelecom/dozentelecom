DOZENTELECOM INSTALL

1. Install Node.js 20+.
2. Run: npm install
3. Copy .env.example to .env and set MongoDB, Paystack, mail/KYC values and:
   SME_API_URL=https://smeapi.com.ng/api
   SME_API_KEY=YOUR_SME_API_KEY
4. Run: npm run dev
5. Open http://localhost:3000

SME API credentials are server-side only. Do not expose SME_API_KEY in NEXT_PUBLIC variables.
